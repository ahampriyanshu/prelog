# Museum image reuse

These five images depict public-domain artworks and are released under Creative Commons Zero (CC0 1.0) through The Metropolitan Museum of Art Open Access initiative. Object API records each report isPublicDomain=true. Original image bytes are retained; museum attribution and per-file provenance are in asset-provenance.json.
