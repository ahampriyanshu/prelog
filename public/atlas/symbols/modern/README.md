# Modern flag icons

237 original 4:3 SVG assets from flag-icons 7.3.2, licensed under MIT. The complete license is retained in LICENSE.txt; provenance.json records package integrity, per-file hashes, identity matches, and exclusions.

Use only when the selected snapshot is the modern reference. The catalogue's historic entities, non-state actors, and claim polygons must not inherit these icons. The artwork is a display adaptation, not a national flag construction standard. Symbols do not establish recognition or sovereignty. The EH asset represents the Sahrawi Arab Democratic Republic, not an uncontested flag over all Western Sahara.

No assets are assigned for ambiguous units, Somaliland, Northern Cyprus, Afghanistan's conflicting flag representation, or Antarctica's unofficial design. The package date/version does not establish historical adoption dates; manifest start/end deliberately remain null.

Reproduce with: `python3 scripts/download-modern-symbols.py --natural-earth /path/to/ne-countries.geojson`.
